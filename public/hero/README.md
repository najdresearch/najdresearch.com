# Najd Research Tuwaiq image pack

Ready-to-use formats derived from the licensed Jabal Tuwaiq photograph and the
Najd Research visual identity.

- `najd-tuwaiq-master-wide.jpg` — clean wide photographic master, 1800×1101
- `najd-tuwaiq-master-square.png` — expanded clean square master, 1254×1254
- `najd-tuwaiq-x-header.jpg` — X header, 1500×500
- `najd-tuwaiq-linkedin-header.jpg` — LinkedIn/company header, 1584×396
- `najd-tuwaiq-post-landscape.jpg` — landscape/link-preview post, 1200×630
- `najd-tuwaiq-post-square.jpg` — square post, 1080×1080
- `najd-tuwaiq-post-portrait.jpg` — portrait feed post, 1080×1350
- `najd-tuwaiq-story.jpg` — story/reel cover, 1080×1920
- `najd-tuwaiq-image-pack.zip` — complete ready-to-share bundle
