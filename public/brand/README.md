# Najd Research logo pack

All files use the same refined Jabal Tuwaiq silhouette.

- `najd-avatar-black.png` — primary social avatar on black, 1024×1024
- `najd-avatar-white.png` — social avatar on white, 1024×1024
- `najd-avatar-green.png` — Saudi-green social avatar, 1024×1024
- `najd-email-profile.png` — Gmail profile image, 512×512
- `najd-x-header.png` — X profile header, 1500×500
- `najd-mark-black-transparent.png` — black standalone mark, transparent, 2048×2048
- `najd-mark-white-transparent.png` — white standalone mark, transparent, 2048×2048
- `najd-lockup-black-transparent.png` — horizontal black wordmark, transparent, 2400×800
- `najd-lockup-white-transparent.png` — horizontal white wordmark, transparent, 2400×800
- `najd-research-logo-pack.zip` — ready-to-share bundle

Use the black avatar for X, the white avatar for Gmail, and the transparent
versions when placing the identity into layouts. The green avatar is an accent
option rather than the default.
